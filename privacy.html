سياسة الخصوصية | Privacy Policy

تطبيق Awabid Automation أداة شخصية يستخدمها مالكها فقط. يصل التطبيق إلى قناة YouTube الخاصة بالمالك عبر YouTube Data API لرفع الفيديوهات وجدولتها وضبط الصور المصغرة وقراءة قائمة الفيديوهات المجدولة. لا يجمع التطبيق أي بيانات من مستخدمين آخرين، ولا يبيع بيانات ولا يشاركها مع أي طرف.

تُحفظ بيانات الاعتماد فقط كأسرار مشفرة في إعدادات مستودع GitHub الخاص بالمالك، ولا تُنشر. يمكن للمالك إلغاء الإذن في أي وقت من myaccount.google.com/permissions.

This app is a private tool used only by its owner. It accesses only the owner's own YouTube channel through the YouTube Data API to upload and schedule videos, set thumbnails and list scheduled videos. It collects no data from other users and does not sell or share any data. Credentials are stored only as encrypted GitHub Actions secrets. Access can be revoked at any time at myaccount.google.com/permissions.

The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
